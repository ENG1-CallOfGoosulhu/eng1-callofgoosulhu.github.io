Initial CRC Cards

Class Name Responsibilities Collaborators
Main (later Cog, MainMenuScreen, GameScreen) Sets up the game window, loads the Tiled campus map, centres the camera on the player, and runs the main render loop. GameWorld, GameTimer, Player
GameWorld Acts as a facade to store all active entities in a list and call their gameStart(), update(), and render() methods each frame. Entity, Player, Goose, HiddenEvent
Entity (Abstract) Base class holding shared 2D coordinates (x, y) and abstract loop methods for world objects. None
Player Handles student avatar movement, map boundary collisions, and sanity level. Entity, InputManager, Inventory
InputManager Polls keyboard inputs (WASD movement and P pause key) so keybinds are kept in one class. None
GameTimer Counts down from 5 minutes (300 seconds), toggles pause state, and draws the Scene2D pause overlay. InputManager, Utilities, MainMenuScreen
Goose & GooseAI Controls autonomous goose wandering, vision cone and hearing circle detection, and non-violent player chasing. Entity, Player
Inventory & Item Stores player items and applies non-violent distraction or transformation effects. Player, Goose, GameWorld
HiddenEvent Triggers hidden campus map interactions (hiding spots, mud, bread dispenser, portal key). Entity, Player, GameWorld
